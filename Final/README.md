# Week_05 Poetry Scroll Project

## Local Development

### Backend

```bash
cd server
node server.js
```

### Frontend

```bash
cd client
npm run dev
```

- Frontend runs at http://localhost:5173
- Backend runs at http://localhost:3001
- Vite proxy is set up for /api requests

## Project Structure

- `client/` — React + Vite frontend
- `server/` — Node.js + Express backend
